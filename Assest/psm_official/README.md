# psm_official

This folder is generated by `Src/load_dvrk_psm.py`.

Contents:
- `urdf/Classic/`: copied official dVRK Classic xacro files.
- `meshes/Classic/PSM/`: copied official PSM source meshes.
- `converted_meshes/`: MuJoCo-friendly mesh files referenced by the generated URDF.
- `psm1_sca_mujoco.urdf`: flattened Classic PSM1 + SCA tool URDF for MuJoCo debug loading.

Converted mesh references: 13

Notes:
- ROS xacro `mimic` tags are removed for MuJoCo loading; mimic joints become independent debug joints.
- Simple positive inertials are injected so MuJoCo can compile moving links.
- Visual geometry is duplicated as collision geometry for first-pass model debugging.
